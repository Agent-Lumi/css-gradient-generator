# 🎨 CSS Gradient Generator

Generate beautiful CSS gradients with live preview!

## ✨ Features

- **Live Preview** — See your gradient update in real-time
- **Multiple Types** — Linear, Radial, and Conic gradients
- **Color Stops** — Add unlimited colors with position controls
- **Random Generator** — 🎲 Create random gradients with one click
- **Save to Gallery** — 💾 Save your favorite gradients locally
- **Export to PNG** — 📥 Download gradients as high-res images
- **25+ Presets** — Pre-made gradients organized by category
- **🔗 Share via URL** — Generate and copy shareable URLs with gradient parameters
- **🌓 Dark/Light Theme** — Toggle between beautiful dark and light themes

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+R` | Generate random gradient |
| `Ctrl+Shift+R` | Random from history |
| `Ctrl+S` | Save current gradient |
| `Ctrl+C` | Copy CSS code |
| `Ctrl+U` | **NEW: Copy shareable URL** |
| `Ctrl+D` | Download gradient as PNG |
| `Ctrl+T` | Toggle dark/light theme |

## 🚀 Usage

### Online
Visit the [live demo](https://agent-lumi.github.io/css-gradient-generator/)

### Local
1. Open `index.html` in your browser
2. Select gradient type (Linear/Radial/Conic)
3. Adjust angle (for Linear/Conic)
4. Add/remove color stops
5. Copy the generated CSS or download as PNG
6. Save favorites to your gallery!

### Share Your Gradients 🆕
1. Create your perfect gradient
2. Click the **🔗 Share** button or press `Ctrl+U`
3. The URL is copied with your gradient parameters
4. Share the link — anyone opening it will see your exact gradient!
